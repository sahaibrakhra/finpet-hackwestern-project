# FinPet for iOS

Open `FinPet.xcodeproj` in Xcode 16 or newer, select an iPhone simulator, and run the FinPet scheme. The deployment target is iOS 17.

## Demo flow

1. Pick, name, and customize a mascot in Home. You can also select a photo.
2. Open Learn, complete Emergency funds, and return Home to feed the earned treat.
3. In Money, set a savings goal, then add a Savings/Investments contribution. Return Home to see the shield fill.
4. In Trends, filter by region, compare spending to the same days last month, and log a confidence check-in.

The profile is saved locally. The starter uses manual and mock transactions. AI video generation and live banking are future provider integrations. Financial examples are educational and use hypothetical amounts.
